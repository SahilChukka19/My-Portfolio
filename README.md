A minimalist, academic-style portfolio designed specifically for an AI/ML Engineer. The design language takes heavy inspiration from **Jupyter Notebooks**, research papers, and technical documentation, featuring clean typography, cell-based layouts, and an interactive neural network hero section.

---

## 🚀 Engineering Highlights

### 📓 Jupyter Notebook Aesthetic
The layout is structured around "Input" and "Output" cells (e.g., `In [1]: About`, `Out [3.1]: Problem`). This creates a semantic, familiar interface for developers, researchers, and technical recruiters.

### 🧠 Interactive Neural Network
A custom-built, responsive neural network visualization powered by SVG and Framer Motion. It acts as an interactive hero background, tracking mouse movements and highlighting active nodes and hidden layers in real-time.

### 📊 Expandable Project Cells
Project details utilize Framer Motion's `layout` transitions. When clicked, project cards smoothly expand to reveal a detailed "Output Cell" containing a deep-dive into the technical problem, execution strategy, and solutions.

---

## 🛠️ Technical Stack

- **Frontend Core**: React 18 (Functional Components, Hooks)
- **Animations**: Framer Motion (Orchestrating layout transitions and spring physics)
- **Styling**: Tailwind CSS (Tailored light-mode 'paper' color palette)
- **Iconography**: Lucide React
- **Build Tool**: Vite (Lightning fast HMR and optimized production bundling)

## 🏁 Getting Started

### 1. Requirements
- Node.js (v18 or higher)
- npm or yarn

### 2. Installation
```powershell
# Clone the repository
git clone https://github.com/SahilChukka19/My-Portfolio.git

# Enter the directory
cd My-Portfolio

# Install dependencies
npm install
```

### 3. Development
```powershell
# Launch the local development server
npm run dev
```
